# RailOps AI Agent

An AI engineering portfolio project for UK railway disruption and journey recovery.

The project currently integrates live UK rail data with LLM tool calling and official CORPUS railway reference data for deterministic station-code resolution.

## Current Features

- Live UK train data integration via Rail Data Marketplace
- LLM function/tool calling
- Agentic tool-calling loop
- Station name → CRS code resolution using official CORPUS location data
- XML reference-data parsing

## Roadmap

- Multi-tool orchestration
- Disruption detection and recovery recommendations
- RAG over enterprise-style operational data
- Persistent agent memory
- Structured evaluation
- FastAPI service
- Docker and cloud deployment
- CI/CD

> This project uses public UK railway data and synthetic enterprise-style data for demonstration purposes.
